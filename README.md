# Description du projet  

Ce projet est une application Python en ligne de commande (console) permettant de gérer une   bibliothèque.  
Il offre les fonctionnalités essentielles pour administrer des livres : ajout, suppression,   recherche, emprunt et retour.  

Les données sont sauvegardées dans un fichier JSON, ce qui permet de conserver les informations   même après la fermeture du programme.  

Ce projet a pour but principal de renforcer les bases du langage Python à travers un cas   pratique proche de la réalité.
